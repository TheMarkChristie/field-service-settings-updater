# Operations Handbook — Fan-Owned Club

Adoption-ready policy drafts covering the business side of running the
fan-owned club. Each document is marked DRAFT until the board formally
adopts it (and, where flagged, a solicitor has reviewed it). The
platform's commitments calendar tracks the recurring obligations these
policies create.
