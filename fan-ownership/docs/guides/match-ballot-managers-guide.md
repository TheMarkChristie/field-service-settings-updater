# Match & Ballot Managers' Guide

## Matchday runbook
1. **Before**: create the match (Owners → Match Centre types) with
   kick-off, venue, opponent; publish — the match-day FanPress chat
   opens automatically. Check stream health and the rota.
2. **During**: start the stream (Cloudflare); live chat runs beside
   it; minute-by-minute via the reporter console; open the live
   player-of-the-match vote.
3. **After**: enter the score, mark finished — the chat transcript
   archives into the match thread automatically (held/removed messages
   excluded, erased members anonymised); publish highlights; POTM
   result feeds player honours and player-of-the-month.

## Ballot runbook
1. **Draft**: create the ballot — the question is the post content
   (images/video welcome); options one per line as `Answer | longer
   description`; set type (standard/constitutional) and the window.
2. **Approve**: a second person must approve (you cannot approve your
   own). Publish.
3. **Open**: happens automatically at the open time — electorate and
   weights snapshot at that moment, the discussion chat spawns, the
   electorate is notified. Options lock.
4. **While open**: running tally is board/staff-only. Members change
   votes freely until close. Ballot lives at /owners/ballot/N/.
5. **Close**: automatic — quorum checked, result computed and
   published, decision register entry created. Failed quorum and ties
   follow the governance rules (board casting vote, recorded).
Never edit a live ballot: withdraw (audited, announced) and reissue.
