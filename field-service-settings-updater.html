2 · Settings To Apply

Tick a setting to include it in the bulk update (changing a control ticks it for you). Unticked settings are not changed.

⚠ Start & End Location are linked: if either is set to Location Agnostic, Field Service requires the other to be Location Agnostic too. Resource Address needs a geocoded address on the related record; Organizational Unit Address needs the org unit to have an address. The preview checks all of this per resource (see the Address column).

3 · Work Hours Advanced
Work hours are stored as a calendar (recurring rules), set via the Field Service msdyn_SaveCalendar API.
Weekly Pattern
Times the resource can be booked per slot.
Copy From A Resource
Reads the source's work-hour calendar for a representative week and recreates that weekly pattern (working hours + breaks, in UTC) on every selected resource. Irregular per-date overrides on the source are not copied.

4 · Quick Actions - Skills & Territories

These act immediately on the resources selected above. Remove asks you to click twice to confirm.

Field Service Mobile — New Mobile Experience

Assigns/removes the Field Service – New Mobile Experience security role on the selected User resources' system users (non-User resources are skipped). The environment-level toggle is managed separately in the Field Service Mobile app settings.

5 · Normalize Calendar Time Zones

Updates calendar-rule time zones while preserving the displayed wall-clock times. Preview first to see the rule counts for every selected resource.

Holidays/business closures are not selected by the Time Off option. Working-hour breaks inherit the working recurrence update.

6 · Delete Calendar Rules

Loads calendar rules for the selected resources. Preview, select only the rules that should be removed, then delete. This operation cannot be undone.

7 · Export Calendar Rules

Exports flattened parent and inner calendar rules for the resources selected in Section 1. The CSV includes resource context, organizational and geographic fields, calendar IDs, common rule fields, and every additional scalar rule property returned by Dataverse.

Reduce this value if Dataverse reports throttling.

8 · Calendar Time Zone Mismatch Audit

Compares each selected Bookable Resource's Time Zone with its calendar rules. Preview mismatches, export the audit, or fix selected rules so they match their own resource while preserving displayed wall-clock times and Time Off reasons.
